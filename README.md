## 5. Cấu trúc thư mục
- `index.html`: Trang giao diện chính chứa nội dung Portfolio.
- `css/style.css`: Tệp định dạng giao diện tông màu xanh và responsive.
- `assets/`: Chứa hình ảnh minh họa dự án.
- `docs/evidence-index.md`: Bảng minh chứng kiểm thử chức năng.
- `docs/AI_LOG.md`: Nhật ký khai báo quá trình sử dụng AI.
- `README.md` & `CHANGELOG.md`: Tài liệu hướng dẫn và lịch sử cập nhật phiên bản.
